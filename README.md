\# Python Finance Calculator



A beginner Python finance calculator that calculates savings, savings rate, and provides a savings assessment.



\## Project Overview



The calculator asks the user to enter their monthly income, monthly expenses, and monthly investment. It then calculates their savings and savings rate. The savings assessment helps the user understand their savings performance based on the calculated savings rate.



\## Features



\* Accepts monthly income, expenses, and investment information from the user.

\* Calculates monthly savings after expenses and investment.

\* Calculates the user's savings rate as a percentage of income.

\* Provides a savings assessment based on the calculated savings rate.

\* Displays financial results in a clear and readable format.



\## Savings Assessment



The calculator uses the following thresholds to assess the user's savings rate:



| Savings Rate | Assessment            |

| ------------ | --------------------- |

| 20% or more  | Strong savings rate   |

| 10% – 19.99% | Moderate savings rate |

| Below 10%    | Needs improvement     |



> \*\*Note:\*\* These thresholds are used as a simple benchmark for this beginner project and are not intended to provide financial advice.



\## How It Works



The calculator follows these steps:



1\. The user enters their monthly income.

2\. The user enters their monthly expenses.

3\. The user enters their monthly investment.

4\. The program calculates savings by subtracting expenses and investment from income.

5\. The program calculates the savings rate as a percentage of income.

6\. The program assesses the savings rate using predefined thresholds.

7\. The results are displayed to the user.



\## Calculations



\### Savings



```text

Savings = Income - Expenses - Investment

```



\### Savings Rate



```text

Savings Rate = (Savings / Income) × 100

```



\## Example



For example, if a user enters:



| Input              | Amount    |

| ------------------ | --------- |

| Monthly investment | GHS 1,000 |

